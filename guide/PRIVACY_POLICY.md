# Privacy Policy for Case Changer

Effective date: 11 September 2026 (first published 3 September 2026)

Case Changer is a Google Docs add-on made by Ikhwan Ariff ("we", "us"). It changes the case of text you select in a Google Docs document, for example to UPPERCASE, lowercase, Title Case or Sentence case.

## What the add-on can access

When you install Case Changer, Google asks you to grant two permissions:

- **View and manage documents that this application has been installed in** (`documents.currentonly`). This lets the add-on read the text you select and write it back in the new case. It cannot open any other document in your Google Drive.
- **Display and run third-party web content in prompts and sidebars inside Google applications** (`script.container.ui`). This lets the add-on show its menu and sidebar.

## What we collect

Nothing. Case Changer does not collect, store, transmit or share any personal information or document content.

- The text you select is processed inside Google's Apps Script platform and written straight back into your document. It is never sent to us or to any third party.
- We keep no copies of your documents or text.
- We do not use cookies, analytics, advertising or tracking of any kind.
- We do not see your name, email address or Google account details.

## How your data is protected

We treat the content of your document as sensitive data, even though we never keep any of it. These are the protection mechanisms in place:

- **Processing stays inside Google.** Case Changer runs entirely on Google's Apps Script platform, in your own Google account. The selected text is read, converted and written back by code running on Google's servers. It never leaves Google's infrastructure and is never sent to a server run by us or by anyone else.
- **No storage and no retention.** The add-on has no database, no file storage, no logging of document content and no user properties. The text exists only in memory for the fraction of a second the conversion takes, then it is discarded. There is nothing to retain, so nothing is retained.
- **Encryption in transit.** All communication between Google Docs, the sidebar and Apps Script happens over HTTPS (TLS), managed by Google. We add no network calls of our own.
- **Least privilege.** The add-on asks only for `documents.currentonly`, which limits it to the document it is open in, and `script.container.ui`, which lets it draw a menu and a sidebar. It cannot list, open or read any other file in your Google Drive.
- **Access control.** Only the developer named on this page has access to the add-on's source project, protected by the developer's Google account with 2-step verification. No third party has access to the code or the project.
- **No third parties.** No analytics, advertising, tracking, crash-reporting or other third-party services are included. Your data is never sold, shared or transferred to anyone.
- **Open source.** The complete source code is public at https://github.com/workingwithkwan/case-changer, so anyone can confirm that it does what this policy says.
- **Revocation.** You can remove the add-on's access at any time (see below). Because nothing is stored, revoking access ends all processing immediately and completely.

If you believe there has been a security problem with Case Changer, email workingwithkwan@gmail.com and we will respond within 7 days.

## Google API Services User Data Policy

Case Changer's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Removing the add-on

You can uninstall Case Changer at any time from **Extensions > Add-ons > Manage add-ons** inside Google Docs, or revoke its access at https://myaccount.google.com/permissions. Because we store nothing, there is no data for us to delete.
