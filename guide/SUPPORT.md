# Case Changer Support

## How to use it

1. Install Case Changer from the Google Workspace Marketplace.
2. Open a Google Doc and highlight the text you want to change.
3. Choose a style from **Extensions > Case Changer**, or open the sidebar for one-click buttons.

Available styles: UPPERCASE, lowercase, Sentence case, Title Case, Capitalize Each Word, iNVERSE cASE and aLtErNaTiNg cAsE.

Bold, italic, colours, fonts and links are kept exactly where they were.

## Common questions

**The menu says "Select the text you want to change first."**
Nothing was highlighted. Click and drag over some text, then run the command again.

**Case Changer is not in the Extensions menu.**
Reload the document page. If it is still missing, check **Extensions > Add-ons > Manage add-ons** and make sure Case Changer is turned on for this document.

**Can it undo a change?**
Yes. Press **Cmd+Z** (Mac) or **Ctrl+Z** (Windows) straight after, or use **File > Version history**.

**Does it work in Sheets or Slides?**
Not yet. Case Changer currently supports Google Docs only.

**Does it send my text anywhere?**
No. The text is changed inside Google's own servers and written straight back into your document. Nothing is collected or stored. See the Privacy Policy.
